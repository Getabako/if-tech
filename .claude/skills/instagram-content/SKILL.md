# Instagram Content Skill

## Overview

This skill provides guidelines and templates for creating engaging Instagram content for if(Tech) programming school.

## When to Use

- Creating post captions
- Planning content calendars
- Developing hashtag strategies
- Writing engaging hooks
- Optimizing for Instagram algorithm

## Content Templates

### Educational Post
```
【今日の学び】${topic}

${main_content}

${key_takeaway}

詳しくはプロフィールのリンクから！

${hashtags}
```

## Caption Best Practices

### Hook (First Line)
- Use 【】 brackets for categories
- Start with emoji when appropriate
- Ask questions to engage
- Use numbers ("3つのポイント")

### Body
- Keep paragraphs short (1-2 lines)
- Use line breaks for readability
- Include specific details
- Tell stories when possible

### Call to Action
- Profile link reference
- Comment invitation
- Save/share encouragement
- DM invitation

### Emoji Usage
- 📚 Learning/Education
- 🎮 Gaming
- 💡 Ideas/Tips
- 🏫 School/Classroom
- 👨‍🏫 Teachers
- 👦👧 Students
- 🎉 Events/Celebrations
- ✨ Magic/Wonder

## CSV Format Reference

```csv
day,theme,caption,hashtags,image_prompt,image_setting
```

| Field | Description |
|-------|-------------|
| day | Day number (1-30) |
| theme | Content category |
| caption | Full post caption |
| hashtags | Space-separated hashtags |
| image_prompt | AI image generation prompt |
| image_setting | imagerule.csv reference |

## Engagement Tips

1. Respond to comments within 1 hour
2. Use Instagram Stories for daily updates
3. Create carousel posts for tutorials
4. Save important posts to Highlights
5. Cross-promote with Reels
